## English

- Holodori-Auto provides High & Low, Fishing, Jump Rope, Cooking and Raft Chess in one window. All five features share language settings and Start/Stop shortcuts. Focused setting fields follow the active feature's color.
- Raft Chess progresses through available Normal and Challenge stages. It confirms moves using visible tile markings, hats and legal positions when characters obscure the board. The optional energy refill uses one in-game item at a time.
- Development and maintenance references are indexed in the [technical documentation](https://github.com/harrykuang-dev/Holodori-Auto/blob/v1.2.10/document/README.md).

Extract the Windows `.7z` and run `Holodori-Auto.exe` from the extracted folder. The source ZIP includes the pinned feature sources. `SHA256SUMS.txt` contains both archive checksums.

## 繁體中文

- Holodori-Auto 在同一個視窗提供比大小、釣魚、跳繩、料理和浮台棋。五個功能共用語言及開始／停止快捷鍵，設定欄位的焦點邊框會跟隨當前功能的配色。
- 浮台棋會推進可遊玩的 Normal 與 Challenge 關卡。盤面受角色遮擋時，程式會依可見的浮台標記、棋帽及合法局面確認走法。啟用自動補充能量後，每次使用一瓶遊戲道具。
- 開發與維護資料已整理至[技術文件索引](https://github.com/harrykuang-dev/Holodori-Auto/blob/v1.2.10/document/README.md)。

解壓 Windows `.7z` 後，在解壓資料夾執行 `Holodori-Auto.exe`。原始碼 ZIP 包含各功能的固定版本來源，兩個壓縮包的校驗值可見 `SHA256SUMS.txt`。
