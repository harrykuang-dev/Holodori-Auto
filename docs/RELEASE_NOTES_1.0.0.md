# Holodori-Auto v1.0.0

## 繁體中文

- 整合 High & Low、釣魚、跳繩與料理，保留各功能的遊戲邏輯、操作與紀錄。
- 共用六種介面語言及可儲存的開始／停止快捷鍵，切換功能時沿用設定。
- 統一 Fluent 導覽與設定介面；點擊左下角 v1.0.0 可開啟專案頁面。
- 包含釣魚快捷鍵初始化修正，以及跳繩對透明 NVIDIA 覆蓋層的判斷修正。
- Windows x64 可攜式套件包含執行環境與料理模型。

下載全部三個 `Holodori-Auto-v1.0.0-windows-1of3.zip`、`Holodori-Auto-v1.0.0-windows-2of3.zip` 與 `Holodori-Auto-v1.0.0-windows-3of3.zip`，解壓至同一個位置，使內容合併為一個 `Holodori-Auto` 資料夾，再執行其中的 `Holodori-Auto.exe`。請保留完整資料夾，無須另行安裝 Python。壓縮檔校驗碼見 `SHA256SUMS.txt`。

## English

- Combines High & Low, Fishing, Jump Rope, and Cooking while preserving each module's game logic, controls, and records.
- Shares six interface languages and saved Start/Stop shortcuts across modules.
- Unifies Fluent navigation and settings; clicking v1.0.0 in the lower-left corner opens the project page.
- Includes the fishing shortcut initialization fix and the jump rope fix for transparent NVIDIA overlays.
- The portable Windows x64 package includes runtime dependencies and cooking models.

Download all three `Holodori-Auto-v1.0.0-windows-1of3.zip`, `Holodori-Auto-v1.0.0-windows-2of3.zip`, and `Holodori-Auto-v1.0.0-windows-3of3.zip` archives. Extract them into the same destination so their contents form one `Holodori-Auto` folder, then run `Holodori-Auto.exe` inside it. Keep the complete folder together; no separate Python installation is required. Archive checksums are provided in `SHA256SUMS.txt`.
