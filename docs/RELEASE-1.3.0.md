# Holodori-Auto v1.3.0

## English

- The standard Windows package includes DirectML for Jump Rope and Cooking. Jump Rope requires a GPU supported by DirectML or TensorRT. Cooking can fall back to CPU.
- Compatible NVIDIA GPUs can use the optional shared TensorRT component. Close the program, extract `Holodori-Auto-v1.3.0-tensorrt.7z` into the folder containing `Holodori-Auto.exe`, then start the program again. The component belongs in `accelerators/tensorrt/` beside the executable.
- The repository contains the source of High & Low, Fishing, Jump Rope, Cooking and Raft Chess. The five features share navigation, language, shortcuts and a Windows build. Existing user data keeps its previous locations.

Download `Holodori-Auto-v1.3.0-windows.7z` and keep the full folder after extracting it. See the [README](https://github.com/harrykuang-dev/Holodori-Auto/blob/v1.3.0/README.md) and [licensing and corresponding source](https://github.com/harrykuang-dev/Holodori-Auto/blob/v1.3.0/LICENSES.md).
