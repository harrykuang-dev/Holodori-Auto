## English

- Updated High & Low to **1.1.2**. Fixed initial double-up prompts being mistaken for successful double-ups when their text overlaps.
- Updated Cooking to **1.1.1**. Start now automatically loads and warms up the selected model, then attempts to bring the game to the foreground and starts. Stop cancels loading; the separate Load model button has been removed.
- Resizing or maximizing the window is preserved when switching modes. Each mode adapts to the current window size.
- Matched Start/Stop button heights across all four modes, including Fishing's compact layout.
- Updated all six README languages, component versions and source notices. Fishing remains **1.1.2** and Jump Rope remains **1.3.0**.

Download `Holodori-Auto-v1.1.1-windows.7z`, extract it with 7-Zip, and run `Holodori-Auto.exe`. Keep the complete folder together. Existing settings and records are preserved.

Windows 10/11 x64 is required. Jump Rope requires a compatible GPU. The first TensorRT load may take longer while building the engine cache.

`Holodori-Auto-v1.1.1-source.zip` includes the integration code and all four pinned submodule source trees. GitHub's automatically generated source archives do not include submodules. See [licensing and corresponding source](https://github.com/harrykuang-dev/Holodori-Auto/blob/v1.1.1/LICENSES.md).
